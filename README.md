# E-Commerce Sales & Business Analytics using MySQL

## Project Overview

This project focuses on analyzing e-commerce business data using MySQL. It helps understand customer behavior, product performance, order trends, payments, and customer reviews through SQL queries.

## Objectives

* Analyze customer and order data.
* Identify top-selling products and product categories.
* Calculate sales and revenue metrics.
* Analyze payment statuses and methods.
* Understand customer reviews and ratings.
* Practice SQL queries based on real-world business scenarios.

## Database Tables

The project database is designed around six tables:

1. `customers` – Customer information
2. `products` – Product details, categories, and prices
3. `orders` – Customer orders and order statuses
4. `order_items` – Products and quantities in each order
5. `payments` – Payment methods, amounts, and statuses
6. `reviews` – Customer ratings and feedback

## SQL Concepts Used

* Database and table creation
* Primary keys and foreign keys
* Constraints
* `insert`, `select`, `update`, and `delete`
* `where`, `order by`, and `group by`
* Aggregate functions
* Joins
* Subqueries
* Business data analysis

## Tools Used

* MySQL
* MySQL Workbench
* GitHub

## Key Learning Outcomes

* Designing a relational database
* Connecting tables using primary and foreign keys
* Writing SQL queries to answer business questions
* Understanding how databases support business analytics

## Project Status

This project is created for learning and portfolio development. Data validation and reconciliation of order totals and payments should be completed before using the results for business reporting.
